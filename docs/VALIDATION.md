# 2026-10-21 扩展验收

环境：Windows 11、64 位 Python 3.12、PyInstaller 6.22.3。仅针对当前源码与本地构建结果，不构成所有型号的实机认证。

- `python -m unittest -v test_devices test_zowie_models`：28 项通过。包含系列阈值差异、量化边界、未知型号与固件保护、型号/固件改变清除缓冲、断开清除状态、设置保存、旧 U2 接收器不发送 DW 命令、多个接收器拒绝查询，以及接收器版本检查与只读请求序列。
- 11 个已记录哈希的鼠标镜像：全部通过公开脚本的离线执行核对，90112 组电压算术输入无差异；启动、正常运行和充电分支的 ADC 转折与证据 JSON 一致。
- 8507、8511 接收器镜像：各 792 组只读查询离线执行，回复一致、缓存未修改。
- 源码版和独立 EXE：均通过实际常驻生命周期脚本，包含后台启动、三次托盘恢复/隐藏、重复启动、面板隐藏后读取鼠标和耳机、临时目录中的自启动快捷方式创建/读回/移除、彻底退出。
- 打包版界面：检查设备概览、偏好设置、型号选择窗口、型号列表及保存后刷新操作。
- 本机 EC2-DW（2524 / 8511）和 G5 MAX：新版读取回归通过；原有自启动配置保留。

其他型号依照[支持矩阵](ZOWIE_SUPPORT.md)标记离线验证或待验证。未执行固件升级、配对、重置或未知命令扫描；固件及原始设备记录不公开分发。
