# PULSE 桌面界面

## 视觉

界面以浅银、冰青与低饱和蓝色为主色，用柔和光晕、圆角轮廓、薄边缘高光和半透明叠层表达液态玻璃质感。设备名称、电量与连接状态保持清晰的文字对比；颜色用于辅助区分状态，不替代文字说明。

Pillow 生成并缓存玻璃底图与设备插图，Tk Canvas 叠加文字、控件与动画。玻璃折射、模糊和半透明效果均以应用内背景为来源，不采集桌面画面，不声称 Windows 原生窗口穿透。设备插图用于类型识别，不表示设备的真实照片或型号外观。

圆角按钮、开关、图标、状态圆点、电量条、动态光圈、玻璃边缘与设备插画采用 4 倍超采样，再以 LANCZOS 缩小至实际显示尺寸。背景光丝独立按目标尺寸的 2 倍绘制，避免大窗口下放大低分辨率轮廓。图片与覆层对齐到同一像素网格，文字保留 Tk 原生字体渲染；动画更新图片时释放过期引用，并限制缓存数量与内存。

## 交互与后台

- 悬停反馈突出当前可点击区域；点击提供短暂的光效反馈。
- 设备页与设置页切换、设备分页使用短过渡；刷新时显示进行中的同步反馈。
- 卡片、设置与详情使用一致的圆角、间距和状态色；保留键盘刷新及设置快捷键。
- 关闭面板后停止界面动画，查询和托盘继续运行；从托盘恢复同一面板。
- 动画在 Tk 主线程执行，设备 I/O 由工作线程负责。静态玻璃与插图复用缓存，退出时清理回调。

## 数据状态

有效百分比直接显示设备返回值，包括 0%。只有电压或原生档位的设备继续显示对应单位或文字，不据此编造百分比。卓威缓存电压注明采样时间未知，高档不等于充满。

旧值使用灰色并明确标注“非当前值”；没有有效读数时显示等待或不可用状态，不能把缺失读数当作 0%。设备连接、充电与读取状态各自采用真实数据，接收器存在不代表外设在线。更多协议边界见 [DEVICE_SUPPORT.md](DEVICE_SUPPORT.md)。

## 运行与验证

源码版需要 Windows、64 位 Python 3.10+、tkinter，以及 `requirements.txt` 中的 `Pillow>=11.3.0,<13`。通过 `python -m pip install -r requirements.txt` 安装运行依赖；PyInstaller 构建的便携版包含 Pillow。

界面验证覆盖默认及最小窗口尺寸、三设备与分页、空状态、百分比与原生档位、旧值、设置与详情、悬停和点击反馈，以及隐藏后停止视觉动画。现有生命周期与协议回归继续适用，实机测试条件见 [ARCHITECTURE.md](ARCHITECTURE.md)。
